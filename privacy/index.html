隐私政策

最后更新：2026 年 10 月 29 日

欢迎访问 M-finder。本文说明本站在提供博客内容、评论和广告服务时，可能涉及哪些信息，以及你可以如何管理相关选择。

访问本站

浏览本站无需注册账户。本站托管于 GitHub Pages；访问页面时，托管服务可能处理 IP 地址、浏览器和设备信息等访问数据。具体处理方式请参阅 GitHub 隐私声明。

如果你主动通过电子邮件联系本站，我会使用你提供的邮箱地址和邮件内容处理、回复你的来信。

第三方广告

本站通过 bauval.org 加载第三方广告脚本。加载广告时，你的浏览器会与该域名及广告服务涉及的第三方服务器通信。

你可以通过浏览器设置管理第三方 Cookie 和站点权限。

评论与外部网站

本站使用 giscus 提供评论，评论存储在 GitHub Discussions。加载评论组件或发表评论时，你的浏览器会与 giscus、GitHub 通信；发表评论需要登录 GitHub。相关数据处理请参阅 giscus 隐私政策和 GitHub 隐私声明。

本站文章可能包含其他网站的链接。访问这些网站时，适用对方的隐私政策。

联系与更新

如对本站的隐私做法有疑问，或希望处理你向本站提交的信息，请发送邮件至 yf-wu@qq.com。涉及第三方账户或服务中的数据，也可以通过相应服务提供的渠道管理。

本站的服务发生变化时，本页会相应更新，并标明最近更新日期。
